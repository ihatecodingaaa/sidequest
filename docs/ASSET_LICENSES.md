# Asset licences

**There are no third-party assets in SIDEQUEST.**

Not one image, not one font file we host, not one sound, not one sprite, not one
icon downloaded from a pack. This file exists so that claim is written down and
checkable, and so that the moment it stops being true there is an obvious place
where the exception has to be recorded.

**Last audited:** 1 September 2026.

---

## Audio

| Asset | Source | Licence |
| ----- | ------ | ------- |
| Every sound effect (about thirty cues) | Synthesised at runtime from the note and envelope tables in `src/lib/audio/cues.ts` | Original. No file exists |
| Ambience bed and one-shots | Synthesised at runtime by `src/lib/audio/engine.ts` | Original. No file exists |
| Streets and interior music | Note tables in `src/lib/audio/engine.ts`, scheduled against the Web Audio clock | Original. No file exists |

**SIDEQUEST ships zero audio files.** Every sound is generated from oscillators
and one procedurally filled noise buffer at runtime. There is nothing to
license because there is no recording: a synthesised triangle wave cannot
contain anybody else's audio.

Specifically and explicitly: no Nintendo audio, no Pokemon audio, no ripped game
sound, no fan recreations, no audio packs, no sample libraries, no
AI-generated audio.

The melodic content is original. It was written as note tables in A minor
pentatonic, not transcribed from any existing work, and the direction in
`docs/AUDIO_ART_DIRECTION.md` deliberately refuses the wide ascending fanfare
that is the most recognisable feature of the games this product admires.

`tests/unit/integrity.test.ts` fails the build if any audio file appears under
`src` or `public`, if any component constructs an `Audio` element or an
`AudioContext`, or if the audio engine is statically imported outside its own
directory.

## Visual

| Asset | Source | Licence |
| ----- | ------ | ------- |
| All illustration, character portraits, mission worlds, Echo, scene art | Original SVG drawn in code | Original |
| The district, sprites, terrain, interiors | Drawn procedurally to a canvas by `src/features/streets/game/world-engine.ts` | Original |
| App icons | Generated by `scripts/generate-icons.mjs` from the original mark | Original |
| Interface icons | `lucide-react`, ISC licence | ISC, permissive, bundled via npm |
| Typefaces | Plus Jakarta Sans and Space Grotesk, served by `next/font/google` | SIL Open Font License 1.1 |

`docs/VISUAL_ART_DIRECTION.md` carries the rule: everything visual is original
and drawn in code, with no stock photography, no downloaded illustration, no
third-party character art, no AI-generated imagery and no brand logos beyond
naming an official service in text.

## If this ever changes

The order is: verify the licence, record the source and the licence in this
file, then vendor only what is used. A clean designed placeholder beats
attractive filler with unclear provenance.

For audio specifically, the bar is higher than a permissive licence. A sound
that is legally clear but recognisably from another game still fails the test in
`docs/AUDIO_ART_DIRECTION.md`: if a knowledgeable player could reasonably say
"that is basically the Pokemon sound", it does not ship.
